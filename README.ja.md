Revvy は、直してほしいところを「言葉で説明する」のではなく「見せて伝える」ための macOS ネイティブアプリです。どのアプリを使っていてもスクリーンショットを撮り、枠・矢印・テキスト・ピクセル単位のルーラーで書き込み、GitHub の Issue やリンクとして共有できます。撮影・書き込み・コピー・保存はアカウントなしで使えます。

> **状態:** 開発初期（0.x）です。未完成の部分や、互換性のない変更があり得ます。

## 機能

**どこからでも撮影**
- ScreenCaptureKit による範囲撮影・全画面撮影
- どのアプリを使っていても効くグローバルショートカット（標準は範囲 <kbd>⌃⇧4</kbd>、全画面 <kbd>⌃⇧3</kbd>）。設定で変更できます
- すべてのアプリの手前に浮かぶ小さな撮影パネル。ボタンひとつの大きさに畳めます
- メニューバーから撮影・ルーラー・設定を呼び出せます
- マルチディスプレイ対応。範囲選択はすべてのディスプレイに表示され、ドラッグした画面を切り出します
- ドラッグ＆ドロップ（Finder、ブラウザ、写真、macOS のスクリーンショットのサムネイル）、クリップボード、ファイルからの取り込み

**書き込み**
- 枠・矢印・ペン・テキスト（4 色）
- 図形の選択・移動・サイズ変更。描画中でも近くの図形をそのまま掴めます（<kbd>⌥</kbd> を押すと重ねて描画）
- 矢印キーで 1px 単位の微調整（<kbd>⇧</kbd> で 10px）、複製、削除、取り消し／やり直し
- 元画像のピクセルで測る距離ルーラー（px・em・両方）
- 書き出しには含まれない座標ルーラーとセンターガイド
- 10〜400% のズーム、ピンチ操作、手のひらツールでの移動（100% は元画像 1px を画面 1pt で表示）

**画面ルーラー**
- スクリーンショットを撮らずに、どのアプリの上でも寸法を測れます
- ドラッグで移動、辺をドラッグでサイズ変更、矢印キーで移動、<kbd>⌥</kbd>＋矢印でサイズ変更
- 10px ごとの目盛り、センターガイド、複製、複数同時表示
- 画面の端から端まで引く縦線・横線のガイド線。位置と、平行な線どうしの距離を表示
- ルーラーとガイド線はスクリーンショットにも写るので、測った状態のまま共有できます

**残して、探す**
- サイドバーの撮影履歴とメモ
- 端末内の文字認識（Apple Vision）で、画像の中の文字から履歴を検索
- 認識した文字のコピー、書き込み済み画像のコピー、PNG 保存

**GitHub に共有**
- GitHub のデバイスフローで連携（Client Secret 不要、トークンは Keychain に保存）
- 書き込み済みスクリーンショット・ラベル・担当者つきで Issue を作成。環境情報（アプリのバージョン、macOS、機種、ディスプレイ）を自動で追記
- 画像をアップロードしてリンクをワンクリックでコピー
- Issue の本文ではトークン、JWT、`Authorization`／`Cookie` ヘッダー、メールアドレスを自動で伏せ字にします

## 動作環境

- macOS 15 Sequoia 以降
- 画面収録の許可（最初の撮影時に求められます）
- GitHub アカウント（GitHub 連携の機能を使う場合のみ）

## インストール

### ダウンロード

署名・公証済みのビルドを [Releases](../../releases) で公開します。`.dmg` をダウンロードし、**Revvy** を **アプリケーション** フォルダへドラッグして開いてください。

### 自分でビルドする

[ソースからビルドする](#ソースからビルドする) を参照してください。

### 初回起動

1. Revvy を開きます。画面の右上付近に撮影パネルが出ます。
2. 最初の撮影をします。macOS が **画面収録** の許可を求めるので、**システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で Revvy を許可します。
3. それでも撮影できない場合は、Revvy を終了して開き直してください（macOS は再起動後に許可を反映することがあります）。

## 使い方

### 撮影

| 操作 | 動作 |
| --- | --- |
| <kbd>⌃⇧4</kbd>（グローバル）または撮影パネルの範囲ボタン | ドラッグで範囲を選択。すべてのディスプレイに表示されます。<kbd>Esc</kbd> でキャンセル |
| <kbd>⌃⇧3</kbd>（グローバル）または画面ボタン | ポインタのあるディスプレイ全体を撮影 |
| <kbd>⌘⇧V</kbd>、またはツールバーの **撮影 ▾ → クリップボードから貼り付け** | クリップボードの画像を使う |
| ドラッグ＆ドロップ | Revvy のウインドウか撮影パネルに画像を落とす |
| ツールバーの **撮影 ▾ → 画像ファイルを開く…** | 画像ファイルを開く |

Revvy のウインドウと撮影パネルはスクリーンショットに写りません。画面ルーラーとガイド線は、測った状態を残せるよう写ります（マウスを乗せたときだけ出るボタンは写りません）。撮影が終わると、ルーラーとガイド線はすべて画面から消えます。<kbd>Esc</kbd> で撮影をやめたときは残ります。

撮影パネルの **×** を押すとボタンひとつの大きさに畳まれ、そのボタンを押すと元に戻ります。パネルを完全に隠すには、メニューバーのメニュー、設定、またはショートカットを使います。

### 書き込み

キャンバス下部のパレットからツールを選びます。

- **選択・移動** — 図形をクリックで選択、ドラッグで移動。矢印とルーラーは端点をドラッグして調整
- **ルーラー** — ドラッグで計測。<kbd>⇧</kbd> で水平／垂直
- **枠**・**矢印**・**ペン** — ドラッグで描画。既存の図形の近くをドラッグすると移動、<kbd>⌥</kbd> で重ねて描画
- **テキスト** — クリックした場所に文字を置き、<kbd>↩</kbd> で確定（<kbd>⌥↩</kbd> で改行）。置いた文字は、テキストツールならクリック、他のツールならダブルクリックで編集
- **手のひら** — 拡大中にドラッグで表示位置を移動

ツールバーの共有メニューから **画像をコピー** や **PNG で保存…** ができます。コピー・保存・共有されるのは書き込み済みの画像です。ガイド、座標ルーラー、選択枠は書き出されません。

### 画面ルーラー

撮影パネルのルーラーボタン、メニューバーのメニューの **画面にルーラーを追加**、または <kbd>⌃⌘R</kbd> で、ポインタの位置に 320×200 のルーラーが出ます。

- 内側をドラッグで移動、辺や角をドラッグでサイズ変更
- 矢印キーで 1px 移動（<kbd>⇧</kbd> で 10px）、<kbd>⌥</kbd>＋矢印でサイズ変更
- <kbd>⌘D</kbd> で複製、<kbd>⌘;</kbd> でセンターガイド、<kbd>Esc</kbd> または <kbd>⌘W</kbd> で閉じる
- マウスを乗せるとガイド・複製・閉じるボタンが出ます。右クリックでも同じ操作ができます
- <kbd>⌃⌘T</kbd> ですべてのルーラーとガイド線を隠す／表示

**ガイド線** — 撮影パネルの縦線・横線ボタン（メニューバーのメニューやルーラーの右クリックメニューからも可）で、ポインタの位置に画面の端から端までの線を引きます。ドラッグか矢印キー（<kbd>⇧</kbd> で 10px）で動かせます。ラベルにはディスプレイの左端・上端からの距離と、平行な線があればその間隔を表示します。<kbd>⌘D</kbd> で複製、<kbd>Esc</kbd> か <kbd>⌫</kbd> で削除。グローバルショートカットは設定で割り当てられます。

サイズはポイント単位で、CSS の px と同じ尺度です。単位（px／em）はルーラーの設定に従います。

### GitHub に共有

1. **GitHub と連携** を押し、ブラウザでコードを承認します（デバイスフロー）。
2. インスペクタで共有先のリポジトリを選びます。
3. **リンクを作成してコピー** で、書き込み済み画像をアップロードして URL をコピーします。
4. **Issue を作成** で、タイトル（空欄なら本文の 1 行目）、コメント、スクリーンショット、ラベル、担当者、環境情報つきの Issue を作成します。

画像は Issue 本文に埋め込まず、専用ブランチ（標準は `feedback-assets`）の `screenshots/` にコミットします。公開リポジトリでは画像も公開され、非公開リポジトリではアクセス権のある人だけが見られます。ローカルの履歴を消しても、GitHub 上のデータは消えません。

組織のリポジトリでは、組織側で OAuth App の承認が必要な場合があります。

## キーボードショートカット

| ショートカット | 動作 | 効く範囲 |
| --- | --- | --- |
| <kbd>⌃⇧4</kbd> | 範囲を選んで撮影 | グローバル（変更可） |
| <kbd>⌃⇧3</kbd> | 画面全体を撮影 | グローバル（変更可） |
| <kbd>⌃⌘R</kbd> | 画面にルーラーを追加 | グローバル（変更可） |
| <kbd>⌃⌘T</kbd> | ルーラーの表示切替 | グローバル（変更可） |
| — | 撮影パネルの表示切替 | グローバル（設定で割り当て） |
| — | 縦／横のガイド線を追加 | グローバル（設定で割り当て） |
| <kbd>⌘⇧V</kbd> | クリップボードの画像を使う | アプリ内 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 取り消し／やり直し（入力中は文字、それ以外は注釈） | アプリ内 |
| <kbd>⌘D</kbd> | 選択中の注釈・ルーラーを複製 | アプリ内／ルーラー |
| <kbd>⌫</kbd> | 選択中の注釈を削除 | キャンバス |
| 矢印キー | 1px 移動（<kbd>⇧</kbd> で 10px） | キャンバス／ルーラー |
| <kbd>⌘+</kbd> <kbd>⌘-</kbd> <kbd>⌘1</kbd> <kbd>⌘0</kbd> | 拡大・縮小・実寸・全体表示 | キャンバス |
| <kbd>⌘;</kbd> | センターガイド | キャンバス／ルーラー |
| <kbd>⌘↩</kbd> | Issue を作成 | インスペクタ |

<kbd>⌘⇧3</kbd>・<kbd>⌘⇧4</kbd>・<kbd>⌘⇧5</kbd> は macOS 標準のスクリーンショットが使うため、グローバルショートカットには登録できません。

## 設定

**Revvy → 設定…**（<kbd>⌘,</kbd>）またはメニューバーのメニューの **設定…** から開きます。

- **ショートカット** — グローバルショートカットの登録（押してからキーを入力。<kbd>Esc</kbd> で中止、<kbd>⌫</kbd> で解除）、撮影パネルの表示、既定に戻す。他のアプリが同じ組み合わせを使っている場合は警告します
- **ルーラー** — 表示する単位（px・em・両方）と、em の計算に使うルートの `font-size`
- **Issue** — 自動で付けるラベル（標準 `app-feedback`）と、スクリーンショットを置くブランチ（標準 `feedback-assets`）
- **GitHub 連携** — フォーク向けの OAuth App Client ID の上書き

## プライバシー

- 撮影した画像、注釈、メモ、認識した文字は Mac の中（`~/Library/Application Support/Revvy/Captures`）にだけ保存します
- 文字認識は Apple Vision を使って端末内で行います
- GitHub のトークンは macOS の Keychain に保存します
- 解析・広告・クラッシュ収集の SDK は入っておらず、開発者へは何も送信しません
- データが Mac の外に出るのは GitHub 連携の機能を使ったときだけで、送信先は選んだリポジトリだけです

詳しくは [PRIVACY.md](PRIVACY.md)（[日本語](PRIVACY.ja.md)）を参照してください。

## ソースからビルドする

必要なもの: macOS 15 以降、Xcode 26 以降、[XcodeGen](https://github.com/yonaskolb/XcodeGen)

```bash
brew install xcodegen
git clone https://github.com/<owner>/revvy.git
cd revvy
make run    # Xcode プロジェクトを生成し、ビルドして起動
```

そのほかのコマンド:

```bash
make open   # プロジェクトを生成して Xcode で開く
make build  # build/ に Debug ビルド
make test   # Swift Testing のテストを実行
make clean  # ビルド成果物と生成したプロジェクトを削除
```

Xcode プロジェクトは `project.yml` から生成するため、リポジトリには含めていません。

### コード署名

標準ではアドホック署名なので、Apple Developer のアカウントは不要です。アドホック署名はビルドのたびに変わるため、画面収録の許可や Keychain へのアクセスを再度求められることがあります。日常の開発では自分の証明書で署名してください。

```bash
cp Config/Local.xcconfig.example Config/Local.xcconfig
# DEVELOPMENT_TEAM を自分のチーム ID に変更
make build
```

`Config/Local.xcconfig` は Git の管理対象外です。

## フォークを配布する

1. **Bundle ID** — `project.yml` の `PRODUCT_BUNDLE_IDENTIFIER` を変更します（内部のモジュール名は経緯により `IssueShot` のままです）。
2. **GitHub OAuth App** — <https://github.com/settings/applications/new> で自分の OAuth App を作り、**Device Flow** を有効にして、Client ID を `IssueShot/OAuthConfig.swift` に設定します。デバイスフローは Client Secret を使わないので、Client ID は公開して問題ありません。
3. **Developer ID で配布** — Developer ID Application 証明書と公証用の資格情報を用意して:

   ```bash
   make notary-setup TEAM_ID=YOUR_TEAM_ID APPLE_ID=you@example.com
   make dist TEAM_ID=YOUR_TEAM_ID              # 署名・公証・ステープル → dist/Revvy-<version>.dmg
   TEAM_ID=YOUR_TEAM_ID ./scripts/dist.sh --no-notarize   # 署名とパッケージのみ
   ```

   DMG にはインストール画面（背景とアイコンの配置）が付きます。`pip3 install --user dmgbuild pillow` が必要で、無い場合は素の DMG になります。アプリアイコンを変えたら `python3 scripts/make-dmg-background.py` で背景を作り直してください。

4. **Mac App Store（任意）** — App Sandbox を有効にした `AppStore` 構成、プライバシーマニフェスト、書き出し用スクリプトを同梱しています。[docs/APP_STORE.md](docs/APP_STORE.md) を参照してください。

## ディレクトリ構成

```
IssueShot/
  IssueShotApp.swift        アプリの入口、メニュー、メニューバー
  AppModel.swift            撮影・注釈・履歴・GitHub の状態
  CaptureControls.swift     グローバルショートカット、撮影パネル、撮影の入口
  Models/                   注釈、図形計算、表示倍率、GitHub のモデル
  Services/                 画面撮影、画像ドロップ、ホットキー、GitHub クライアント／認証、履歴と文字認識、伏せ字
  Views/                    SwiftUI／AppKit のビュー（エディタ、サイドバー、インスペクタ、パネル、画面ルーラー、設定）
  Resources/                String Catalog、プライバシーマニフェスト、アイコン
IssueShotTests/             Swift Testing のテスト
Config/                     署名とビルドの設定
scripts/                    配布用スクリプト
docs/                       追加のドキュメント
```

## 既知の制限

- 動画・GIF の録画には対応していません
- 共有は GitHub リポジトリのブランチを使います。独立した画像ホスティングはないため、非公開リポジトリのリンクはアクセス権のない人には開けません
- 画面収録の許可を変更したあとは、アプリの再起動が必要な場合があります
- 公式ビルドに同梱している GitHub OAuth App の登録名は、まだ「IssueShot」のままです
